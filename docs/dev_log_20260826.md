## 三、 深度核心技術與數學模型

### 1. 船艏內傾夾角演算法（Inward Bow Cant Angle）

#### 🛑 設計動機
在 BHV_Trail 的原始實作中，當子船抵達包夾站位（進入 adius 捕獲半徑）後，本船航向會被鎖定在目標船航向上，兩艇與目標維持完全平行（Parallel）。這種態勢在視覺與避碰上較似「護航」而非「主動逼退」。

#### 💡 幾何模型與符號決策 (cantAngle & slotCant)
系統保持站位點座標與目標匹配速度不變，僅在生成航向 IvP 客觀函數時將期望航向偏轉：
\text{Heading}_{\text{usv}} = \text{Heading}_{\text{tgt}} + \text{cant\_signed}

`
                           目標航向 (Heading_tgt)
                                     ▲
                                     │
                 [左舷子船]          │          [右舷子船]
                 船艏向右內傾        │          船艏向左內傾
                     \               │               /
                      \  +cant_deg   │   -cant_deg  /
                       \             │             /
                        *            │            *
                         \           │           /
                          \          │          /
                           ──────────┼──────────
                               [目標 Target]
`

1. **左右舷自動符號映射**：
   根據子船站位相對目標航向的角度差 $\text{rel} = \text{angle180}(\text{SlotAngle}_i - \text{Heading}_{\text{tgt}})$：
   - 若 $\text{rel} > 0$（子船在目標**右舷**）：中心線在左側，$\text{cant\_signed} = -\text{cant\_deg}$（向左偏轉）。
   - 若 $\text{rel} < 0$（子船在目標**左舷**）：中心線在右側，$\text{cant\_signed} = +\text{cant\_deg}$（向右偏轉）。
   - **效果**：操作員只需給定單一正值 $\text{cant\_deg} \in [0^\circ, 90^\circ]$，左右兩翼子船即可**同步向內切入**。
2. **中心死區保護（cant_dead_deg = 5°）**：
   若站位落在目標正前方或正後方 ^\circ$ 內，因內傾方向無唯一解，自動將內傾角歸零，防止感測微擾導致船艏在左右舷高頻擺動。

---

### 2. 相對航向座標系（station_frame = relative）

* **原理**：母船協調器在發布 TRAIL_UPDATE_<VNAME> 時，下發相對於目標航向的固定相對角（如 $+45^\circ, -45^\circ$），不再每秒發布絕對羅經度數。
* **效果**：站位點完全由子船 Helm 在本地以 4Hz 高頻即時疊加目標最新艏向計算，**徹底消除了跨網路傳輸絕對方位造成的站位點步進跳躍與劇烈抖動**。

---

### 3. 動態陣型即時切換機制（Dynamic Formation Switching）

透過岸端圖台發布 EVICT_FORMATION，支援在任務運行中即時無縫切換三種核心陣型：
1. **lock（地面固定阻擋）**：切換為地面固定座標路障，啟動自適應間距收縮與航渡鎖定。
2. **herd（動態阻擋弧）**：切換為隨動動態阻擋弧，支援即時配置 spread、	rail_range 與 cant（例：mode=herd,spread=90,cant=20）。
3. **stern（尾隨跟蹤）**：切換為傳統後方尾隨。

## 四、 大規模批次模擬實驗與結論

### 1. 空間幾何評估指標
- **目標逃逸航行距離（{\text{travel}}$）**：目標從被接戰到首次被驅逐出防禦邊界期間實際航行之軌跡弧長積分（單位：公尺），消除了 =D/v$ 的速度尺度偏差。
- **路徑迂迴比（$\text{Tortuosity} = D_{\text{travel}} / D_{\text{shortest}}$）**：衡量目標退場路徑是否筆直無繞行（理想直線退場 $\to 1.0$）。
