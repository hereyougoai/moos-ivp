## 三、 各模組功能與演算法詳細解析

### 1. COLREGS 避碰強度階層式選單與行為持久化

#### 🎯 解決痛點
在多無人船演習或演示過程中，操作員常需依任務需求動態切換無人船的避碰激進程度（例如示範嚴格遵守國際規則時需提早大角度轉向，而在演示極限戰術逼退時需允許貼近封堵）。

#### 🛠️ 具體實作
1. **4 級避碰靈敏度定義**：
   - **Strong（強 - 提早行動、寬闊繞行）**：
     `pwt_inner=28m, pwt_outer=60m, min_util_cpa=18m, max_util_cpa=30m, headon_thresh=30°`
   - **Moderate（中 - 系統預設調優參數）**：
     `pwt_inner=20m, pwt_outer=45m, min_util_cpa=12m, max_util_cpa=20m, headon_thresh=22.5°`
   - **Weak（弱 - 延後行動、近距離掠過）**：
     `pwt_inner=10m, pwt_outer=25m, min_util_cpa=6m, max_util_cpa=12m, headon_thresh=15°`
   - **Minimal（微 - 最後數米極限防撞）**：
     `pwt_inner=3m, pwt_outer=8m, min_util_cpa=2m, max_util_cpa=4m, headon_thresh=12°`
2. **通訊下發機制**：
   - 透過 `CONTACT_INFO_ALL` 與 `TGT_AVD_INFO_ALL` 發送無 `name=` 標籤的更新字串，`pHelmIvP` 會自動將該配置同步套用至該 Behavior 模板的所有存活用戶端（Live Instances）。
3. **實例持久化（Behavior Instance Retention）**：
   - 將 `completed_dist` 設定為 300m（大於 280x120m 區域的對角線 ~305m）。
   - 避免目標船暫時遠離時行為實例被 Helm 判定 Completed 而銷毀；若銷毀後重新接觸將會以 `.bhv` 預設值重生，導致先前選單設定失效。持久化確保操作員的選單指令在整場任務中持續鎖定。

---

### 2. 系統技術文檔與理論模型架構化

#### 🎯 目的
統整系統核心演算法模組與社群通訊協議，形成標準化技術規範。

#### 🛠️ 核心內容
1. **社群通訊拓撲與 pShare 直送機制**：
   - 詳細記錄母船透過 `pShare` 直送子船（`WPT_UPDATE`、`TRAIL_UPDATE`）的原因與避免死循環機制（當社群同時存在同名變數 input 與 output 時 pShare 會阻斷寫入）。
2. **全量布林狀態覆寫（Complete Mode State）**：
   - 記錄每次切換狀態時發布完整布林值（`SURVEY_ALL`, `TARGET_ALERT_ALL`, `LOITER_ALL` 等）以防止 Helm 卡在舊狀態。
3. **演算法數學模型公式化**：
   - 包含旋轉卡尺法（Rotating Calipers）主軸對齊、逃逸代價函數（`exitCost`）、防禦阻擋弧（Pincer Arc）角度幾何與 Bow Guard 避開目標正前方的偏移計算。

### 3. 邊界防禦牆演算法（Boundary Wall & Inboard Barrier）

#### 🎯 解決痛點
在原先的包夾邏輯中，Pincer 防禦弧線是以「目標逃逸方向的相反方向」作為對稱軸心。當目標船被逼至防禦邊界時，目標若突然貼著邊界大角度轉向，防禦弧線會被目標的航向帶著走，使得原先退出的缺口瞬間失去防守，目標容易藉機反切重返防禦區。

#### 🛠️ 具體實作
1. **幾何邊界最近點與向內法向量計算 (`boundaryInboard`)**：
   - 不採用多邊形質心（Centroid）計算（長條狀 280x120m 區域邊緣朝質心與邊界法向存在高達 90° 偏差），而是遍歷多邊形各線段，計算目標點至邊界的最小垂直投影點 $C(x,y)$。
   - 計算由邊界垂直指向區域內部的向內法向量方位角 $\theta_{\text{inboard}}$。
2. **防禦模式動態切換 (`updateWallMode`)**：
   - 當目標距離邊界小於防禦牆觸發距離 `wallBand`（結合 `wall_dist` 與 `region_exit_buffer`）時，自動切入 **Wall Mode（防禦牆模式）**。
   - 站位對稱軸心強制鎖定在邊界的向內法向 $\theta_{\text{inboard}}$，不再隨目標自身的即時轉向打轉。
   - 夾擊開角由原先的 120° 擴大為 150°（`wall_spread_deg`），站位半徑由 25m 推開至 40m（`wall_range`），形成一道跨度達 77m 的橫向阻絕線。
3. **視覺化與防抖**：
   - 加入退出滯後機制（`wall_hyst`），防止目標在邊界邊緣遊走時狀態來回震盪。
   - 在圖台上即時繪製黃色防禦阻線（`shield_wall`）。
