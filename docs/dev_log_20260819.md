## 二、核心架構與功能修改說明

### 1. `pRegionDivider` 區域劃分與網格追蹤模組
- **搜索區域建立**：支援透過 `pMarineViewer` 的 GUI 滑鼠標點取凸包（Convex Hull），或使用內建預設區域（`REGION:DEFAULT`）。
- **等寬多邊形切分**：根據線上運行的子船數量（如 `abe`、`ben`），由西向東均分搜索區域。
- **航線自動生成**：為各子船自動計算割草機（Lawnmower / Boustrophedon）航點序列，並發布 `WPT_UPDATE_<vehicle>`。
- **掃描覆蓋率視覺化**：根據定義的感測器半徑與網格尺寸（`VIEW_GRID`），即時標記與回傳已掃描水域。

### 2. `pTargetCoordinator` 協同攔截與夾角控制模組
- **目標追蹤與分配**：母船（Mothership）接收各子船回報的目標節點資訊（`NODE_REPORT`）。
- **燕型夾角配置**：動態分配各子船的包夾角度（如 135° 與 225° 側翼站位），計算相對方位並發布 `TRAIL_UPDATE_<vehicle>`。
- **避碰推擠驅逐**：利用目標船的 `pContactMgrV20` 與 `BHV_AvoidCollision`（較高權重），迫使目標船因避讓雙側包夾而轉向撤離任務區。

### 3. `m_shield_demo` 任務拓撲與通訊流程
- **MOOS 社群劃分**：
  - `shoreside` (Port 9000/9200)：操作員圖形介面與總體指令轉發。
  - `abe` / `ben` (Port 9001/9201, 9002/9202)：兩艘執行搜索與包夾的子無人船。
  - `target` (Port 9003/9203)：入侵目標模擬船。
  - `mothership` (Port 9005/9205)：負責分區運算與包夾協調。
- **通訊流向規範**：母船之航點與追蹤指令採 `pShare` 直送各子船，避免與 Shoreside qbridge 路由衝突。

## 三、待改善與問題追蹤事項 (Issue Tracker)

針對當前系統運行測試情況，將後續待優化項目分為「優先處理」與「次要改善」兩大類別：

### 🔴 優先解決事項 (High Priority)

| 項次 | 項目描述 | 現象與問題點分析 | 建議改善方向 |
| :---: | :--- | :--- | :--- |
| **1** | **開啟後重複使用船隻會失控** | 任務重新啟動或重複指派任務時，Helm 行為狀態機未完整重置或有舊更新變數殘留。 | 檢查 `meta_vehicle.bhv` 與 `meta_mothership.moos` 中的重置機制，於部署/重置時清空殘留的 `WPT_UPDATE` / `TRAIL_UPDATE` 並重置 Helm 變數。 |
| **2** | **目標船隻速度過快，缺乏速度差距** | 子船與目標船速差不足，導致攔截耗時過長或無法形成有效夾擊。 | 調整 `launch_target.sh` 或 `meta_target.moos` 中的預設航速（如將 target 降速至 1.0~1.5 m/s），拉大子船追擊優勢。 |
| **3** | **路徑規劃後按下 Deploy 出現短暫誤植多邊形** | 點擊 Deploy 時畫面上會短暫幾秒閃爍錯誤多邊形。 | 檢查 `pRegionDivider` 在接收到 Deploy 觸發信號時的幾何計算時序，確保未完全產生新頂點前不發布未初始化形狀或舊多邊形。 |
| **4** | **遠距按下 Intercept 未即時追蹤** | 子船距離目標過遠時按下 Intercept 無法立即追逐，需靠近到一定距離才動作。 | 調整 `BHV_Trail` / `BHV_CutRange` 的啟動條件（如 `extrapolate_decay` 或距離觸發門檻），確保在操作員切換攔截模式時立即生效航向修正。 |
| **5** | **驅逐僅有單純尾隨，缺乏路徑包夾防衛效果** | 目前子船僅保持相對角度尾隨，缺乏主動封堵與前向包抄路徑。 | 強化 `pTargetCoordinator` 演算，結合航向預測與前方攔截點（Intercept Pincer），形成更具壓迫感的弧形/前置包夾。 |

### 🟡 次要改善事項 (Secondary Priority)

| 項次 | 項目描述 | 現象與需求說明 | 建議改善方向 |
| :---: | :--- | :--- | :--- |
| **1** | **目標船路徑支援使用者自訂規劃** | 目前目標船僅走固定巡邏航線，無法靈活測試不同入侵情境。 | 於 Shoreside GUI（`pMarineViewer`）新增滑鼠標記或自訂航點按鈕，將目標航線動態注入 `meta_target`。 |
| **2** | **搜索範圍面積切割轉彎角度優化** | 目前垂直/等分切割容易使子船在邊界頻繁出現大角度轉向。 | 依據區域幾何的主軸方向（如最小旋轉外接矩形主軸）進行多邊形分割，減少搜索過程中的急轉彎次數。 |
| **3** | **搜查方式多樣化（提供非割草機模式）** | 目前僅支援單一割草機模式，缺乏其他搜索樣式。 | 於 `pRegionDivider` 中擴充螺旋搜查（Spiral）、扇形搜查或向心搜查等多種模式，並於 GUI 提供切換按鈕。 |
| **4** | **搜索路徑整合視距/感測半徑最佳化** | 目前航線間距未充分與感測範圍結合，導致重複掃描與航程浪費。 | 將 `sensor_radius` 參數納入航線間距（Sweep Width）動態計算中，最大化覆蓋效益並縮短總航行距離。 |
