## 一、 8/27 研發背景與核心升級總覽

本日研發聚焦於解決 **m_shield_demo（Shield AI 多無人船協同搜索、包夾與驅逐防衛系統）** 在目標多樣性、阻擋站位平滑化以及物理模擬上限上的多項核心問題：

1. **目標船速度上限（Speed Ceiling Clamp）解鎖**：
   - 解決過去 launch_target.sh 硬編碼 MAX_SPD=1.2 導致 uSimMarineV22 強制截斷、圖台 1.4 / 2.0 / 3.0 m/s 調速失效的問題，預設上限提升至 3.0 m/s。
2. **目標行為多樣化畫像系統（8 大 Target Scenario Profiles）**：
   - 實作 8 種目標行為模板（evader, merchant, sprinter, zigzag, lumbering, loiterer, harasser, dead_ship），並於 Shoreside 圖台新增 Action/Target Profile 即時動態切換選單。
3. **阻擋演算法平滑化與鎖定升級 (pTargetCoordinator)**：
   - 實作目標航向低通平滑濾波（$\tau = 10\text{s}$）、阻擋提前量遲滯鎖定（$\Delta = 10\text{m}$）、讓路撤退點座標鎖定與全域重發頻率保護。
4. **自動化畫像基準測試與軌跡分析套件**：
   - 建立 ench_profile_sweep.sh（30 輪 Headless 批次模擬）與 ench_escape_path_analyzer.py（ALog 空間幾何自動統計）。
