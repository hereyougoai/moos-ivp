## 二、詳細檔案異動與功能變更說明

### 1. 安全作業規範：無人船搖桿與 MOOS-IvP 控制切換 SOP
* **修改/新增檔案**：
  - [`usv_control_switch_safety_guidelines.md`](file:///l:/home/yoei/moos-ivp/usv_control_switch_safety_guidelines.md)
* **核心內容**：
  - **切換模式標準作業程序 (SOP)**：定義手動遙控（RC/Joystick）與自主導引（Autonomous / MOOS-IvP）切換時的訊號交握規範。
  - **安全邊界與安全距離**：規範實體測試防護圍欄（Geofence）與實體驗船間距。
  - **Watchdog 與 Heartbeat 機制**：心跳逾時（Heartbeat Timeout）自動降級安全停俥規範。
  - **緊急處置方案**：緊急停俥（E-Stop）、返航點（Return-to-Home / RTH）以及手動強制作業流程。

* **修改/新增檔案**：
  - [`ivp/src/pTargetCoordinator/TargetCoordinator.cpp`](file:///l:/home/yoei/moos-ivp/ivp/src/pTargetCoordinator/TargetCoordinator.cpp)

  - [`ivp/missions/m_shield_demo/meta_mothership.moos`](file:///l:/home/yoei/moos-ivp/ivp/missions/m_shield_demo/meta_mothership.moos)
* **核心功能**：
  - **扇形封堵與弧形壓迫 (Herd / Pincer Mode)**：子船不再僅是單純在目標後方等角尾隨，而是結合搜索區域中心點（`REGION_CENTER`），計算目標航向與防禦弧線，在目標前方形成夾角壓迫點（Pincer Intercept Points）。
  - **角色切換遲滯區間 (Hysteresis Swap Margin)**：避免兩艘子船因短暫距離交錯而頻繁抖動互換左右翼站位，提升航行平穩度。
  - **視覺化攔截指針**：即時發布預定夾擊點至 GUI 畫面（`VIEW_POINT` / `PINCER_PT`），方便操作員即時監控封堵位置。
  - **航線保留與狀態切換穩定化**：當狀態由搜索切換至攔截時，保留已劃分的搜索航線幾何，避免畫面閃爍或航線丟失。

### 4. 區域搜索與覆蓋演算法升級：`pRegionDivider`
* **修改/新增檔案**：
  - [`ivp/src/pRegionDivider/RegionDivider.cpp`](file:///l:/home/yoei/moos-ivp/ivp/src/pRegionDivider/RegionDivider.cpp)
  - [`ivp/src/pRegionDivider/RegionDivider.h`](file:///l:/home/yoei/moos-ivp/ivp/src/pRegionDivider/RegionDivider.h)
  - [`ivp/src/pRegionDivider/RegionDivider_Info.cpp`](file:///l:/home/yoei/moos-ivp/ivp/src/pRegionDivider/RegionDivider_Info.cpp)
* **核心功能**：
  - **掃描航向主軸對齊 (Principal Axis Sweep Alignment)**：不再固定使用垂直掃描，改依多邊形主軸方向自動調整掃描線角度，減少急轉彎與過彎航程消耗。
  - **感測半徑自適應間距 (Sensor-Radius-Based Spacing)**：依據設定之感測半徑動態計算航線間距（`sweep_width = 2 * sensor_radius * overlap_factor`），確保覆蓋效益最大化。
  - **多種搜索圖形樣式支援**：新增除經典割草機（Lawnmower）外的多種掃描路徑規劃能力（如向內矩形螺旋 Inward Spiral、由外向內收縮等）。
  - **區域中心點即時輸出**：計算凸包質心/邊界幾何中心並發布 `REGION_CENTER`，供攔截協調器計算防禦面。

## 三、待處理事項清單 (To-Do & Action Items)

根據目前的開發進度與系統測試回饋，整理以下待辦與優化事項：

### (一) 待處理與優化事項
1. **控制項介面優化**：
   - 將目前 `pMarineViewer` 上選擇「視距」和「搜索掃描方式」的獨立按鈕，整合改為**下拉選單 (Dropdown Menu)**，提升操作便利性並精簡畫面佈局。
2. **新增多元掃描與巡航模式**：
   - 於搜索路徑模組中再擴充更多掃描方式：
     - **扇形搜尋 (Sector Search)**
     - **屏障攔截巡航 (Barrier / Patrol Line Intercept)**
     - **8 字形巡航 (Figure-Eight Patrol)**
3. **軌跡殘留問題修復 (Trail Points Glitch)**：
   - 修正畫面上灰色的 **trail point 視覺標記殘留** 問題，確保在切換狀態、重新部署或目標消失時能即時清除殘餘圖元。
4. **驅逐判定與狀態自動切換功能 (Expulsion Success & Return-to-Search)**：
   - 新增成功驅逐之判定邏輯：只要目標船隻被成功驅離至子船的**掃描範圍（Sensor Range）外**，即判定驅逐成功。
   - 成功驅逐後，子船的行為狀態機自動由「攔截驅逐（Intercept/Trail）」**切換回「掃描搜索（Search/Survey）」**，並在原分區內繼續巡邏，等待下一次再次偵測到目標船隻。
